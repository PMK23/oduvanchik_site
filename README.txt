САЙТ «ШИНОМОНТАЖ ОДУВАНЧИК»

Файлы:
- index.html — структура сайта (русский язык)
- styles.css — стили и адаптивная верстка
- script.js — каталог услуг, фильтры, модальное окно записи
- assets/logo.jpg — логотип из исходных материалов
- assets/hero.jpg — фото для первого экрана из исходных материалов

КАК ЗАПУСТИТЬ:
1. Распакуйте архив.
2. Откройте index.html в браузере.
3. Для публикации загрузите всю папку на хостинг, сохранив структуру файлов.

ВАЖНО ПРО ЗАПИСЬ:
Форма сейчас работает на стороне браузера: проверяет поля и формирует текст заявки для копирования. Она НЕ отправляет заявку администратору автоматически. Для автоматической доставки заявок, реального календаря свободных слотов и админ-панели нужно подключить backend/API, базу данных и канал уведомлений (например, Telegram-бота).

НЕЗАПОЛНЕННЫЕ ДАННЫЕ:
Город, график работы и стоимость услуги «Проверка балансировки» не были предоставлены. Они не придуманы в коде. Адрес карты указан по переданной строке; проверьте, что карта показывает нужный населённый пункт.
